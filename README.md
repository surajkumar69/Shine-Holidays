## 3. Technology & Architecture

- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS v4 + Custom Luxury Typography (Cinzel, Playfair Display, Outfit)
- **Icons:** Lucide React
- **Features:**
  - Glassmorphic luxury navigation with scroll detection & mobile drawer
  - High-conversion Hero section with starting rate highlight (₹35/KM)
  - Interactive Fleet cards with in-card photo switchers
  - Feature cards with official capabilities
  - Transparent pricing module with journey terms
  - Responsive lightbox modal with keyboard navigation (Esc, Left, Right)
  - Booking enquiry form with validation & instant WhatsApp message formatter
  - Floating WhatsApp action button and mobile sticky call bar
